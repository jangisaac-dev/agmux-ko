작업 중인 스레드를 모아 보는 포커스와 함께 더욱 차분해진 agmux.

이번 업데이트에서는 선택하여 사용할 수 있는 포커스 목록, agmux.dev 및 휴대폰과 통일된 더 깔끔해진 디자인, 한층 세밀해진 계정 관리, 내 Mac에 딱 맞는 로컬 모델이 추가되었으며 검색, 태스크, Teams, 원격 제어 전반의 오류가 개선되었습니다.

### New
- **포커스** — 사이드바 상단에 추가할 수 있는 선택 그룹으로, 모든 프로젝트에서 활발히 작업 중인 스레드를 한데 모아 주어 모든 프로젝트를 열어 둘 필요가 없습니다. 현재 실행 중인 스레드와 최근 10분 동안 활동한 스레드를 나열합니다(설정에서 최대 30분까지 선택할 수 있습니다). "더 보기" 전까지 스레드 7개를 보여 주며, 포커스를 우클릭해 표시 개수를 늘리거나 줄일 수 있습니다. 포커스에서 새 세션을 시작하면 어느 프로젝트에 속할지 묻습니다. 업데이트 후 실제 모습을 미리 보면서 기능을 켤지 한 번 묻는 대화상자가 표시됩니다. 설정 → 일반에서도 켤 수 있습니다.

### Improved
- **더 깔끔해진 디자인** — 앱 디자인이 agmux.dev 및 휴대폰 앱과 통일되었습니다. 새로운 서체, 플랫 패널과 카드, 더 명확해진 라벨, 차분해진 상태 색상이 적용되었으며, Mac과 휴대폰에서 타일을 꽉 채우는 더 또렷한 앱 아이콘도 제공합니다. 이전의 반투명한 스타일을 선호한다면 설정 → 모양 → 표면 → 글래스를 선택하면 됩니다. 기존 글꼴인 Geist는 설정 → 글꼴에 그대로 남아 있습니다.
- **Teams에도 새 디자인 적용** — Teams 웹사이트도 앱과 동일한 서체, 플랫 패널, 색상을 사용합니다.
- **휴대폰 원격 제어 개편** — 휴대폰 및 브라우저 원격 제어 화면이 agmux.dev에 맞춰 더 깔끔해졌으며, 시스템 설정을 따르는 라이트 모드를 지원합니다. 세션 목록이 간결해졌고 각 제목 옆에 시간이 표시됩니다. 헤더가 iPhone 상태 막대와 겹치지 않으며 세션 이름을 가리지 않습니다. 답변 가독성도 개선되었습니다. 제목, 인용문, 표가 올바르게 표시되고, 코드 블록에 복사 버튼이 생겼으며, 도구 동작은 깔끔한 카드로 묶입니다. 화면이 작은 휴대폰에서도 메시지 입력창이 한 줄로 유지됩니다.
- **더 명확해진 계정 설정** — 설정에서 기존 '에이전트 계정'이 이제 **계정**으로 간소화되었고, 기존 '계정' 탭(Git 신원 정보 및 연결된 서비스)은 **Git 및 연결**로 변경되었습니다.
- **더 간소해진 계정** — 설정 → 계정에 '내 계정' 섹션과 소속 팀별 섹션이 나뉘어 구분이 한결 명확해졌습니다. 팀 계정은 해당 팀 섹션에서 추가하면 됩니다. 팀원이라면 누구나 별도 로그인 없이도 팀 계정을 확인하고 사용할 수 있습니다. 사용량 확인 중 요청 한도 초과가 발생하면 이를 안내하고 마지막으로 확인된 수치를 계속 표시합니다. 잘 쓰지 않는 작업은 각 계정의 ⋯ 메뉴로 들어갔으며, 계정 자동 전환 시 현재 로그인한 계정이 이미 우선 사용되므로 '전환 대상에 추가'는 사라졌습니다.
- **이 계정 사용** — Codex나 Grok 계정을 고르고 '이 계정 사용'을 선택하면 CLI가 해당 계정으로 로그인되어 agmux와 터미널 모두에 적용됩니다. 기존에 로그인되어 있던 계정도 계정 목록에 그대로 유지됩니다. 내 CLI가 팀 계정을 사용하는 동안 해당 계정은 내게 체크아웃된 상태가 되므로 팀원들도 사용 중임을 알 수 있습니다. CLI가 사용하는 중에도 사용량이 최신으로 유지됩니다. 특정 계정으로 전환할 수 없는 경우 해당 계정에 바로 이유가 표시됩니다.
- **팀 계정 사용자 확인** — 팀 계정을 현재 누가 사용하고 있는지, CLI로 사용하는 중인지가 표시됩니다. 내 CLI가 팀 계정으로 로그인된 경우 agmux가 이를 인식해 개인 계정이 아닌 해당 팀 소속으로 나열합니다.
- **모든 사용량 한도 표시** — 5시간 및 주간 한도처럼 각 한도가 계정마다 개별 표시되며, 팀 계정에서도 동일하게 확인할 수 있습니다. 30일 또는 월간 한도는 실제 기간에 맞춰 표시됩니다. 오래된 측정값에는 '상태 알 수 없음' 대신 측정 시점이 표시되며, Claude Team 플랜은 이제 'Team 플랜'으로 표기됩니다.
- **계정별 사용 현황 확인** — 현재 팀에서 몇 명이 해당 계정을 쓰고 있는지 표시되며, 자동 전환 시 이용자가 더 적은 계정을 우선 선택합니다. 팀 소유자는 'Claude 공유 계정'을 켜서 각 Claude 로그인을 몇 명이 쓰는지 확인할 수 있습니다. Claude 계정의 이메일은 2명 이상이 사용할 때만 표시됩니다.
- **계정 이름 바꾸기** — 계정의 ⋯ 메뉴에서 이름을 바꿀 수 있습니다. 로그인 정보를 팀과 다시 공유하더라도 팀에서 설정한 계정 이름이 덮어씌워지지 않습니다.
- **팀으로 계정 이동** — 팀 소유자와 관리자는 ⋯ 메뉴에서 개인 계정의 Codex 또는 Grok 계정을 팀으로 이동할 수 있습니다. 현재 로그인된 계정을 이동하면 팀과 공유되어 팀 아래에 나열되며, 내 로그인 상태는 유지됩니다.
- **구독 등급** — 제공자가 정보를 지원하는 경우, Claude의 Max 20x나 Grok의 SuperGrok Heavy처럼 계정에 정확한 구독 등급이 표시됩니다.
- **최신 로컬 모델** — 24GB 이상의 메모리를 갖춘 Mac의 경우, 설정 → 로컬 모델에서 Mac에서 실행 가능한 가장 강력한 코딩 모델인 Qwen 3.8 27B를 추천합니다. 이 모델보다 성능이 떨어지는 기존 모델들은 추천 목록에서 제외되었습니다. 이미 다운로드한 모델은 그대로 계속 사용할 수 있습니다.
- **더 깔끔해진 로컬 모델 화면** — 설정 → 로컬 모델이 내 Mac 및 설정, 추천 모델(메모리 크기를 선택하여 다른 옵션 탐색), 다운로드한 항목, HuggingFace 검색, 에이전트 도구 등 명확한 섹션으로 재구성되었습니다. 이제 모델을 삭제할 때 파일을 지우기 전 확인을 거치며, 라이트 모드도 잘 지원합니다.
- **Claude 터미널 라이트 모드 지원** — agmux가 라이트 모드일 때 Claude 터미널도 Claude의 밝은 색상을 사용하며, 모드를 바꾸는 즉시 라이트와 다크 모드가 전환됩니다. Claude에서 색각 보정 또는 커스텀 테마를 선택한 경우에도 설정이 그대로 유지됩니다.
- **계정 사용량** — 설정 → 계정에서 사용량을 자동으로 확인하므로 새로 추가한 계정도 '사용량 확인'을 누를 필요 없이 한도가 바로 나타납니다. 팀 계정에도 '사용량 확인' 버튼이 제공되며, 빈칸으로 표시되는 대신 마지막으로 확인된 시각과 수치를 계속 보여 줍니다. 사용 중인 계정이 거의 소진되었을 때(5% 이하 남음) agmux가 다른 계정들을 확인해 어떤 계정으로 전환할지 보여 줍니다.
- **모든 에이전트에서 휴대폰 원격 제어 지원** — Droid, Kimi, Cline, Hermes, OpenCode, Gemini 터미널에서 내가 입력한 내용뿐만 아니라 전체 대화가 휴대폰에 표시됩니다. Mac 사이드바에 저장된 Kimi, Pi, Grok 세션도 휴대폰에 표시되며, 에이전트마다 고유 아이콘이 적용되었습니다.
- **휴대폰에서 터미널 요청 승인** — Claude나 Kimi 터미널에서 권한을 요청하면 휴대폰 화면에도 허용 및 거부 버튼이 표시됩니다.
- **배터리 소모 감소** — 창이 백그라운드에 있거나 유휴 상태일 때 agmux가 사용하는 CPU 및 그래픽 성능이 줄어듭니다. 다른 앱을 보고 있는 동안에는 스피너와 상태 애니메이션이 일시 정지되며, 백그라운드 확인은 빈도를 줄이거나 복귀할 때까지 대기합니다.
- **커밋 메시지 모델** — 설정에서 직접 선택할 때와 자동 모드 모두에서 커밋 메시지 작성 모델이 GPT-5.6 Luna 대신 GPT-6 Luna Low로 변경됩니다.
- **휴대폰 원격 제어 개선** — 로딩 중이거나 Mac이 오프라인일 때 상태를 표시하고, 조용히 실패하는 대신 오류를 보여 주며, 작은 화면에서도 현재 모델이 보이도록 유지합니다. iPhone에서 입력할 때 화면이 임의로 확대되지 않고, Mac에서 권한을 해제하면 바로 로그아웃됩니다. 페어링이 멈추던 문제가 해결되었으며 iPhone 앱의 페어링 링크도 정상 작동합니다.

### Fixed
- **휴대폰의 Claude 터미널 답변** — 원격 제어에서 Claude 터미널 답변의 표, 목록, 제목, 코드 블록이 긴 하나의 문단으로 뭉치지 않고 제대로 표시됩니다.
- **파일명 검색** — `main.rs`나 `package.json`처럼 마침표(.)가 들어간 단어로 검색할 때 일치하는 대화를 놓치지 않고 찾아냅니다.
- **IDE에서 폴더 이름 바꾸기 또는 삭제** — 폴더 이름을 바꿀 때 열려 있던 파일도 변경된 경로를 따라가 정상적으로 저장되며, 폴더를 삭제하면 열려 있던 파일이 닫힙니다.
- **사용량의 Codex 초기화 시각** — Codex 사용량 막대에 '지금 초기화' 대신 한도가 실제로 언제 초기화되는지 표시됩니다.
- **IDE 편집기의 "파일을 불러올 수 없습니다" 오류** — 이미지처럼 표시할 수 없는 파일을 연 뒤 다른 파일을 열었을 때, 같은 오류가 계속 표시되지 않고 새 파일이 정상적으로 열립니다.
- **악센트 문자, 일본어, 이모지가 포함된 검색** — ś, せ, 🐛 같은 문자가 포함된 메시지가 검색 결과에서 깨지지 않으며 주변 단어도 정상적으로 검색됩니다. 또한 "śledzenie"나 "せんせい" 같은 단어로 검색할 때도 대화를 제대로 찾아냅니다.
- **검색에서 최근 작업 요약 표시** — 에이전트가 최근 턴에서 수행한 작업 요약을 이제 검색에서 바로 찾을 수 있습니다. 이전에는 다음 턴을 시작할 때까지 검색에 나타나지 않았습니다.
- **명령 팔레트의 세션 시간 표시** — 명령 팔레트의 최근 세션 및 기타 세션에 이제 "지금"(또는 시간대에 따라 몇 시간씩 차이 나는 시간) 대신 얼마나 전에 사용했는지가 표시됩니다.
- **입력한 내용과 일치하는 검색 결과** — 검색 시 이전에 입력 중이던 더 짧은 검색어의 결과가 간혹 표시되던 문제가 해결되었습니다.
- **이름에 공백이 포함된 파일 커밋** — 이름에 공백이나 악센트 문자가 포함된 파일이 커밋 및 PR 생성 목록에 두 번(한 번은 따옴표 포함) 표시되지 않으며, 커밋에 실패하지 않습니다. 이름을 바꾼 파일에는 올바른 새 이름이 표시됩니다.
- **태스크 생성 속도 향상** — 태스크를 생성할 때 많은 디스크 공간을 차지하고 오랜 시간이 걸리던 Claude Code 자체 워크트리 폴더를 더 이상 새 태스크에 복사하지 않습니다.
- **폴더가 삭제된 태스크 삭제** — agmux 외부에서 태스크 폴더가 이미 삭제된 경우에도 "No such file or directory" 오류로 실패하지 않고 태스크 삭제가 정상 작동합니다.
- **새 태스크의 브랜치 변경 사항** — 로컬 main 브랜치가 최신 상태가 아닐 때도 Git 패널의 브랜치 및 커밋 보기와 '커밋'의 커밋 목록에 다른 사람의 main 브랜치 변경 사항 대신 해당 태스크의 자체 작업만 표시됩니다.
- **태스크 풀 리퀘스트 설명** — 로컬 main 브랜치가 최신 상태가 아니더라도 태스크 풀 리퀘스트의 자동 생성 제목과 설명에 해당 태스크의 자체 변경 사항만 반영됩니다.
- **삭제된 태스크 이름 재사용** — 삭제한 태스크와 동일한 이름으로 태스크를 생성할 때 폴더가 이미 존재한다고 표시하는 대신 브랜치 이름이 이미 사용 중임을 안내합니다.
- **태스크에서 Gemini 채팅 보관** — 태스크에서 Gemini 채팅 에이전트 탭을 닫으면 백그라운드에서 계속 실행되지 않고 에이전트가 중지됩니다.
- **채팅 승인 요청 표시 유지** — 채팅에서 두 개의 권한 요청이 대기 중일 때 첫 번째 요청이 1분 이상 지나도 화면에서 사라져 에이전트가 멈추지 않고 계속 유지됩니다.
- **Codex 채팅의 "항상 허용" 정상 작동** — Codex 채팅에서 항상 허용하도록 선택한 명령이 실패하지 않고 자동으로 실행됩니다.
